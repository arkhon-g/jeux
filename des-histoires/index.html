Dés histoires

Lance les dés, puis invente une histoire avec les symboles.

3 dés
Comment jouer
  1. Lance les dés : secoue le téléphone ou touche « Lancer ».
  2. Regarde les symboles. Chacun est un indice pour ton histoire.
  3. Raconte une histoire qui utilise chaque symbole, dans l'ordre que tu veux.

Pour varier :

  • À plusieurs, chacun dit une phrase à tour de rôle, avec un symbole chacun.
  • Un symbole ne t'inspire pas ? Touche le dé pour le relancer seul.
  • Avec 1 dé, c'est le point de départ. Avec 9, c'est un défi.

Il n'y a pas de gagnant. Le but est de raconter.
